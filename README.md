# Sahyog - Civic Problem Solving Ecosystem

Every problem deserves a path to a solution. **Sahyog** is an innovative, fully integrated web platform that connects Citizens, Government Administrators, Academia, and Industry to resolve community challenges effectively and transparently.

## 🌟 Key Features

The platform is designed around four interconnected portals that create a seamless, closed-loop civic innovation pipeline:

### 1. 🗣️ Citizen Portal (Voice-First & Low-Bandwidth)
* **Multilingual Voice Assistant**: An accessible, state-machine-driven Voice Assistant utilizing the Web Speech API to guide illiterate or low-vision users through issue reporting in both English and Hindi (auto-detected).
* **AI Image & Text Analysis**: Integrates **Google Gemini Vision** to analyze citizen-uploaded photos and descriptions, automatically identifying the domain, calculating priority, generating keywords, and routing the issue to the most appropriate academic institution.
* **Low-Bandwidth Optimized**: Uses on-device `browser-image-compression` to drastically reduce image sizes (e.g., from MBs to KBs) before upload, ensuring rural access.

### 2. 🛡️ Govt Admin Dashboard (Human-in-the-Loop & XAI)
* **Explainable AI (XAI)**: Displays exactly *why* the AI routed a specific ticket to a specific university, grounded in regional dataset mockups (CGWB, NBSS&LUP).
* **HITL Routing**: Provides administrators the authority to override AI routing recommendations via a simple dropdown before final validation. 
* **Deduplication Visualization**: Automatically clusters similar incoming tickets into "Merged Duplicates" to prevent redundant academic assignments.
* **Ecosystem Monitoring**: Dedicated tabs to monitor live civic challenges, browse registered academic capabilities, and track industry CSR partners.

### 3. 🎓 University Workspace (NEP 2020 Integration)
* **Multidisciplinary Team Builder**: In alignment with NEP 2020's mandate to break academic silos, universities can form cross-departmental teams (e.g., Computer Science + Civil Engineering) when accepting challenges.
* **Project Lifecycle Tracker**: An interactive UI tracking projects from Validation &rarr; Proposal &rarr; Prototype &rarr; Testing &rarr; Pilot &rarr; Impact.
* **Continuous Feedback Loop**: Upon reaching the "Impact" phase, universities can deploy the solution and feed data back to Government Analytics to retrain the AI routing loop.
* **Impact Metrics**: Dynamically estimates NAAC accreditation points and tracks the number of students engaged in experiential learning.

### 4. 💼 Industry Hub (CSR Deployment)
* **Live Investment Opportunities**: Corporate partners can browse active, university-led civic innovation projects and provide CSR (Corporate Social Responsibility) funding.
* **Dynamic Deployment Tracker**: Automatically tracks total CSR funds disbursed and the number of active pilot deployments generated by their investments.

## 💻 Technologies Used

* **Frontend Framework**: React 18, Vite, TypeScript
* **Styling & UI**: Tailwind CSS, Lucide React Icons
* **Dark Mode**: Fully implemented context-driven light/dark theme toggling
* **AI & Machine Learning**: Google Gemini 2.5 Flash API (Multimodal Vision & Text)
* **Database / State**: Firebase Firestore (for live synced state management across portals)
* **Browser APIs**: Web Speech API (`window.SpeechRecognition`, `window.speechSynthesis`)
* **Utilities**: `browser-image-compression`

## 🚀 Prerequisites & Installation

To run this platform locally on your machine, you'll need the following installed:
* [Node.js](https://nodejs.org/en/) (v16 or higher)
* `npm` or `yarn`

### 1. Clone & Install Dependencies
Navigate to the project directory and install the necessary packages:
```bash
npm install
```

### 2. Environment Configuration
You must provide a valid Google Gemini API key for the AI triage system in the Citizen Portal to function. 
Create a `.env` file in the root directory (next to `package.json`) and add the following line:

```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Start the Development Server
Run the Vite development server:
```bash
npm run dev
```

### 4. Access the Application
Open your browser and navigate to the local host URL provided by Vite (typically `http://localhost:5173`).

## 🧪 Testing the Ecosystem Flow

To experience the full capability of the platform, follow this workflow:
1. **Citizen Portal**: Submit an issue (use the Voice Assistant or standard form) with a photo. Wait for the AI to triage it.
2. **Admin Portal**: Approve and route the newly submitted issue to a university (or override the AI's choice).
3. **University Portal**: Accept the routed challenge, form a multidisciplinary team, and advance the milestone tracker up to the "Pilot" phase.
4. **Industry Portal**: Observe the project appear in the live investment opportunities feed and fund it.
5. **University Portal**: Advance the funded project to the "Impact" phase and trigger the "Deploy & Feed Data to Govt" loop.

*Tip: If you ever need to reset the data back to its original state, click the red **Reset Sandbox Data** button in the Admin Dashboard.*
